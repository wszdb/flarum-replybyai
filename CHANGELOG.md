# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2025-01-XX

### Added
- 🎉 Initial release
- ✨ Smart Reply button on all posts
- 🤖 AI-powered reply generation using OpenAI-compatible APIs
- 📝 Auto-fill reply box with AI-generated content
- ✏️ Editable AI replies before posting
- 🔗 Automatic quote references for non-first-floor replies
- ⚙️ Admin settings panel with full configuration
- 🌐 Multi-language support (English, Simplified Chinese)
- 🎨 Custom styling for Smart Reply button
- 🔒 Permission controls (login required, can't reply to own posts)
- 📏 Content truncation (200 characters max for analysis)

### Features
- Support for any OpenAI API-compatible service
- Configurable model selection (input field, not dropdown)
- Adjustable max tokens for reply length
- Customizable system prompt for AI behavior
- Real-time loading states and error handling
- Responsive design for mobile and desktop

### Technical
- Built with TypeScript and modern Flarum extension structure
- RESTful API endpoint for reply generation
- Secure API key handling
- Comprehensive error handling and logging
- Clean separation of admin and forum components
